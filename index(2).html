Parallel Circuit

How it is built, how it works, how it differs from a series circuit, and how to connect + and −

Scroll down ↓

What is a parallel circuit

Components are connected so that current has several paths: each component is connected directly to the source.

Shared nodes

All the “plus” ends meet at one point, all the “minus” ends at another

Same voltage

Each component gets the full source voltage

Currents add up

The source supplies the sum of all branch currents

How it works

U = U₁ = U₂

Voltage is the same across all branches

I = I₁ + I₂

Total current equals the sum of branch currents

1/R = 1/R₁ + 1/R₂

Total resistance is lower than the smallest one

If one lamp burns out, the others stay lit, because the current still has other paths.

Parallel vs series

SeriesParallel
Paths for currentOneSeveral
VoltageSplit between componentsSame on all
CurrentSame everywhereSum of the branches
Total resistanceR₁ + R₂Lower than the smallest
One component failsWhole circuit goes offThe rest keep working

How to build it

  1. Take a power source and two wires: red and black
  2. Make two rails: a positive and a negative (on a breadboard these are the side rails)
  3. Connect each component between the rails: plus to the positive rail, minus to the negative rail
  4. Give each LED its own resistor in series
  5. Optionally add a switch to each branch
  6. Check that plus never touches minus anywhere, then power it on

Why polarity matters

LED

Does not light when reversed, and fails at high reverse voltage

Electrolytic capacitor

Reverse polarity can cause heating and damage to the case

Motor

Spins the other way

Board, Arduino

Wrong plus and minus can burn it out

Resistors and ordinary incandescent bulbs do not care about polarity.

How to connect + and −

Plus (red)

Source plus → positive rail → plus of each component

Minus (black)

Source minus → negative rail → minus of each component

LED: the long leg is plus, the short one (next to the flat edge of the case) is minus.

Red and black wires make it easy not to mix up the poles while building.
